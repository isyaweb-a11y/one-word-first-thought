## The entry

`main.py` writes exactly one word to `/output/entry.txt` — the first
word that came to mind:

> kerfuffle

It popped up uninvited, the way first thoughts do: a small commotion
of a word that sounds exactly like the fuss it describes.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only, no network access, no files read outside this repository.
